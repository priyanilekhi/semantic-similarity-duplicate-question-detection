Semantic Similarity-Based Duplicate Question Detection
NLP CA3 Mini Project on detecting semantically duplicate question pairs using TF-IDF and Sentence-BERT.
Project Overview
This project investigates whether two questions express the same underlying meaning despite differences in wording and sentence structure. The project compares a TF-IDF baseline with Sentence-BERT embeddings and evaluates performance through subgroup audits and error analysis.
Dataset
Quora Question Pairs
Source: Kaggle Quora Question Pairs Competition
Techniques Used
- TF-IDF with unigrams and bigrams
- Cosine similarity
- Sentence-BERT (all-MiniLM-L6-v2)
- Classification threshold optimisation
- Lexical-overlap and question-length audits
- False-positive and false-negative analysis
